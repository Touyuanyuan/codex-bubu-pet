把相机布布
带到你的桌面

随身带着小相机，认真思考时拿出小电脑。电脑上，还有一二的 wink 大头照。

安装到 Codex ↗

需要已安装并支持宠物 v2 的 Codex 桌面客户端。浏览器可能会询问是否打开 Codex，随后在应用中确认安装。

也可以离线安装 · Windows

  1. 下载发行包，右键选择“全部解压”。
  2. 在解压后的文件夹中双击 install.cmd。
  3. 回到 Codex：设置 → Mini 与虚拟宠物 → 点击“创建虚拟宠物”左侧的小刷新图标 ↻ → 相机布布。

安装脚本无需管理员权限或额外运行环境。不要直接从压缩包预览窗口运行。
